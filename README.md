# mcp-server
Production-ready remote MCP (Model Context Protocol) server on Cloudflare Workers — Personal Knowledge &amp; AI Workspace with D1, KV, R2, Workers AI, Vectorize, and OAuth

The RegisterMySite product API, CLI, and MCP surface is designed in [docs/rms-platform-api.md](docs/rms-platform-api.md). `platform/` is a stub: `npm run rms -- catalog` lists the calls, and the other commands print the request they would send without contacting the product workers.
